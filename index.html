✋ AI 손짓 안전 신호기

손짓을 AI로 인식하고 마이크로비트 LED로 의사를 전달합니다.

1. AI 모델 설정

모델 URL을 입력한 뒤 불러오기를 눌러 주세요.

Teachable Machine에서 이미지 프로젝트를 학습하고 모델 내보내기 메뉴의 공유 URL을 입력하세요.

2. 입력 방식

카메라를 허용하고 손짓을 화면 안에 보여 주세요.

입력 화면이 여기에 표시됩니다.
카메라가 시작되지 않았습니다.

3. AI 인식 결과

?

분석 대기 중

이미지를 분석하거나 카메라를 시작하세요.

인식 신뢰도 기준

최소 신뢰도 80%

기준보다 낮은 결과는 마이크로비트로 전송하지 않습니다.

클래스별 인식 확률

모델을 불러오면 클래스별 확률이 표시됩니다.

4. 마이크로비트 연결

연결되지 않음

USB 케이블로 연결한 후 연결 버튼을 눌러 포트를 선택하세요.

115200bps · UTF-8 · 줄바꿈 종료

수동 전송 시험

모델을 불러오면 학습된 클래스별 버튼이 만들어집니다.

먼저 AI 모델을 불러오세요.

수동 전송은 AI 신뢰도와 무관하게 선택한 클래스를 전송합니다.

5. 인식 기록

  • 아직 인식 기록이 없습니다.

6. 명령 전송 기록

  • 아직 전송 기록이 없습니다.

사용 안내

  1. Teachable Machine에서 이미지 모델을 학습하고 URL을 입력합니다.
  2. 마이크로비트를 USB로 연결하고 MakeCode 프로그램을 먼저 설치합니다.
  3. 마이크로비트를 연결한 다음 카메라 또는 이미지 업로드를 선택합니다.
  4. 신뢰도 기준을 설정하고 손짓을 분석합니다.
  5. AI의 클래스 이름과 마이크로비트의 처리 조건이 일치하는지 확인합니다.

이 장치는 의사소통을 보조하는 학습용 시제품입니다. 실제 긴급 상황에서 유일한 안전 수단으로 사용하지 마세요.
